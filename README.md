# MEAN Static Display Application

This is a simple static web application built using the MEAN stack.

## Description
- Angular frontend displays static text and images.
- Express.js backend serves the built Angular files.
- No database, APIs, or user input are included.

## Technologies Used
- Angular
- Node.js
- Express.js

## Project Structure
- frontend/: Angular application
- backend/: Express server

## How to Run the Project

1. Install dependencies:
   - In `frontend`:
     npm install
   - In `backend`:
     npm install

2. Build the Angular project:
   - From `frontend`:
     ng build

3. Run the Express server:
   - From `backend`:
     node server.js



## Notes
- This project is for static content display only.
- Images are served from the public assets folder.
